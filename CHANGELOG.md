# Changelog

## 1.0.0

Initial release.

- One death resets the overworld, Nether and End for everyone, live, with no server restart.
- Death Hall memorial dimension with a statue and plaque for every death.
- Deaths, Runs and Causes record boards.
- Return portal with lit floor arrows to start the next run.
- /run and /stats for everyone; /ht admin commands for ops.
- Server-only: players join with an unmodified vanilla client.
