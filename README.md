# Hardcore Together

Hardcore for groups: when anyone dies, the world resets for everyone, and every death is remembered in the Death Hall.

- Fabric mod for Minecraft 26.3. Requires Fabric API.
- Server-only: players join with plain vanilla Minecraft. Also works in single-player.
- Warning: the first death deletes and regenerates the overworld, Nether and End. Use a fresh world.

Full documentation is coming soon. Download on CurseForge (link coming soon). Report bugs in [Issues](https://github.com/Shmathew02/HardcoreTogether/issues).
